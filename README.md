## The pitch

> For $1 a meeting, MeetingGhost sends a lazy AI agent to your 9 a.m. standup, where it says 'no blockers' in your voice and naps until someone says your name.

## What it does

`main.py` (Python standard library only) writes that one sentence to `/output/entry.txt`. The pitch is deterministic — the same bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
